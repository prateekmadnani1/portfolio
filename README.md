# Prateek Madnani · Portfolio

Personal portfolio of Prateek Madnani, Senior Technical Product Manager in Seattle.

Case studies, research, product sketches, writing, skills and experience across AI products and cloud platforms in legal tech, healthcare and payments.

## How it's built

A single static page: `index.html`, with no build step and no dependencies beyond Google Fonts. It supports light and dark mode and works at phone width.

Hosted on GitHub Pages. To update the site, edit `index.html` and push to the default branch.
